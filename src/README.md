# LifeOS Landscape Tablet Dashboard — SVG Asset Pack

These SVGs are intended for the LifeOS dashboard shown in the reference UI.

## Included
- Brand: `lifeos-mark.svg`
- Navigation: dashboard, tasks, calendar, fitness, learning, finance, focus, journal, resources, settings
- Utility/action icons: search, bell, moon, plus, chevrons, arrows, check, clock, location, video, external, filter, more, pin
- Dashboard summary icons: overview-tasks, overview-events, overview-workout, overview-learning, overview-finance, overview-focus
- Visualization/status: progress-ring, trend-up, target, sparkline
- Fitness: workout-person, streak, rest-day
- Finance: income, expense
- Weather: sun, cloud

The AI/Jarvis floating chat icon is intentionally NOT included, per request.

All icons use `currentColor` where practical, so they inherit the color from the host UI. They are designed to be reusable at multiple sizes rather than tied to one screenshot resolution.
